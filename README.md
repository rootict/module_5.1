# Module 05.1 - Prompt Anatomy: The 4 Pillars of a Master Prompt

An interactive, web-based presentation designed for the **Foundation Diploma in Digital Technology, AI & Future Skills**. This module introduces students to the core concepts of Prompt Engineering and how to effectively communicate with Generative AI models.

## 🎯 Learning Objectives
This presentation covers the foundational bridge between human intent and AI execution, breaking down a master prompt into four actionable elements:
* **The Task:** Defining the action verb.
* **The Context:** Providing background information and setting the scenario.
* **Constraints:** Setting boundaries, rules, and negative prompts.
* **Output Format:** Structuring the final delivery (e.g., Markdown tables, JSON, code blocks).

## ✨ Features
* **Interactive UI:** Clickable chat simulations comparing "Weak" vs. "Strong" prompts.
* **Visual Filtering:** Live demonstrations of how constraints eliminate unwanted AI hallucinations and jargon.
* **Zero Dependencies:** Built entirely with pure HTML, CSS, and vanilla JavaScript. No external libraries or installations required.
* **Fully Responsive:** Adapts smoothly across different screen sizes and projectors for classroom environments.
